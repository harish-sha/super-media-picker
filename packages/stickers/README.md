# @super-media-picker/stickers

Tree-shakeable static and animated sticker provider adapters for Super Media Picker.

- `MockStickerProvider`: pack navigation, lazy pack items, search, pagination, and deterministic loading/error fixtures.
- `HttpStickerProvider`: host-backend adapter using the shared request/cache layer and response validation.

Animated WebM, WebP, GIF, and Lottie stickers share the React animated-media renderer used by animated emoji. No sticker collection is bundled.
